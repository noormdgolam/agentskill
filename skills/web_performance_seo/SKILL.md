# Web Performance & SEO Skill

## Principles
1. **Structured Data**: Include accurate Schema.org JSON-LD (`RealEstateAgent`, `GeneralContractor`, `PostalAddress`, `GeoCoordinates`) on every page.
2. **Local SEO Meta Tags**: Standardize `geo.region` (BD-C), `geo.placename` (Uttara, Dhaka, Bangladesh), and location coordinates.
3. **Page Load Speed**: Preload web fonts at top of stylesheet, specify explicit `width` and `height` attributes on images, and use native `loading="lazy"`.
