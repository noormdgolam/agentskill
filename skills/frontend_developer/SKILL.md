# Frontend Developer Skill

## Guidelines & Architecture
1. **Component Design**: Build modular, reusable components with clean semantic HTML5 markup.
2. **Styling & CSS**: Use CSS variables for tokens, standard flexbox/grid for layouts, and maintain mobile-first responsive breakpoints.
3. **Accessibility & ARIA**: Use proper `aria-labelledby`, `aria-label`, `role="navigation"`, and keyboard navigation for all interactive UI elements.
4. **Performance**: Avoid unnecessary DOM manipulation, enforce image lazy loading (`loading="lazy"`), and optimize font loading (`font-display: swap`).
